Geometry pass

The browser computes the coordinates

① Declare
<row gap="md">
  <shape w="fill"/>
  <shape w="fill"/>
</row>

Authors declare layout with flex and grid. Coordinates have no place in it.

row · col · grid · stack
② Measure
x · y · w · h
x · y · w · h

Headless Chromium measures every element's box. The pass reads only rects.

getBoundingClientRect
③ Bake
<a:off x="609600"
       y="1714500"/>
<a:ext cx="1562100"
       cy="1066800"/>

Measured rects are the PPTX coordinates. 1px = 9525 EMU, converted once.

a:off · a:ext
The pipeline speaks logical stage px (16:9 is 1280×720). EMU and pt exist only inside the PPTX renderer.

What each tag becomes

SOML PPTX output
<text> · <h1> · <p> · <ul> p:sp text box — carries the resolved rPr
<shape> (16 presets · path) p:sp + prstGeom · custGeom — holds text
<image> (PNG · JPEG · SVG) p:pic — SVG stays vector, with a PNG fallback
<row> · <col> · <grid> · <stack> No shape — dissolves into children's absolute positions
<table> (this slide) p:graphicFrame + a:tbl — an editable table
<chart> · <series> · <point> Shapes + text — one bar is one shape
<connector> p:cxnSp — connectors glued to boxes
enter= · transition= p:timing · p:transition — native entrance effects

Four files make a theme
  • tokens.json — color · type · spacing
  • components.json — roles and variants
  • layouts/*.css — placement, not styling
  • assets/ — backgrounds · logos · icons
Tokens stay names

A token color stays a CSS variable on the web and an a:schemeClr in PPTX. Only literals become srgbClr.
