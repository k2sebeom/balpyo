# 0012 — 공간 토큰에는 PPTX 테마 슬롯이 없다

- 상태: 확정
- 날짜: 2026-08-20
- Iteration: 3 (항목 02 — NOTES.md 03/02가 근거 기록이다)
- 관련: PRD §8.4 (토큰 어휘), §9.4 (외관의 순방향 컴파일),
  [외관 속성](../../docs/reference/appearance.md), [레이아웃 태그](../../docs/reference/soml/layout.md),
  ADR 0010 (링크 색 토큰)

## 맥락

이 제품의 핵심 계약은 **토큰이 참조로 남는다**는 것이다: 색 토큰은 웹에서
`var(--balpyo-color-accent1)`, PPTX에서 `<a:schemeClr val="accent1"/>`로 나가고 실제 RGB는
양쪽 모두 한 곳(테마 층 `:root`, 테마 파트 clrScheme)에만 있다. 그래서 내보낸 파일이
PowerPoint의 테마 색 편집을 따라간다.

레이아웃 태그가 들어오며 `gap="lg"`·`pad="md"` 같은 **공간 토큰**이 어휘에 생겼다
(PRD §8.4의 `space` 스케일 — "배치조차 테마의 리듬을 따라간다"). 색·폰트 토큰이 전부
PPTX 슬롯을 갖는 표에서 이 토큰은 어디에 붙는가.

## 선택지

1. **테마 파트의 어딘가에 공간을 싣는다.** OOXML 테마에는 공간 개념이 없으므로 확장
   파트(`extLst`)나 사용자 정의 프로퍼티에 넣고 우리 도구만 읽는다.
2. **슬롯 없음을 계약으로 인정한다.** 공간 토큰은 웹에서 CSS 변수 참조로 남고, PPTX에서는
   해석된 px가 좌표로 구워진다. 토큰 정체는 산출물에 남지 않는다.

## 결정

**선택지 2 — 슬롯이 없다.** `soml.SpaceToken`은 `ColorToken`과 달리 `Slot`/`Ref` 필드를
갖지 않고, 그 부재가 의도임을 타입 주석과 테마 테스트가 못 박는다.

확정 길이(`soml.Length`)는 토큰 이름과 해석된 px를 **함께** 담는다 — 웹은 이름으로
`var(--balpyo-space-lg)`를 내고, PPTX·진단·테스트는 px를 본다.

## 근거

- **PPTX에서 gap을 고친다는 것은 도형을 옮긴다는 뜻이다.** 배치는 지오메트리 패스가 잰
  좌표로 구워지므로(PRD §9.3) 산출물에 남는 것은 도형의 절대 위치뿐이다. 슬롯을 만들어도
  그 값을 바꿨을 때 따라 움직일 것이 파일 안에 없다 — 색 토큰의 슬롯이 뜻을 갖는 이유
  (뷰어가 참조를 해석한다)가 여기에는 없다.
- **선택지 1은 열어 두면 거짓말이 된다.** 우리 도구만 읽는 확장 파트는 PowerPoint에서
  아무 일도 하지 않으므로, 토큰이 남았다는 사실이 "테마를 바꾸면 여백이 따라온다"는 기대를
  만들고 그 기대가 틀린다. 토큰이 편집 대상이 되는 것은 **SOML 원본에서 다시 빌드할 때**다.
- **비대칭을 감추지 않는 것이 낫다.** 이 제품의 다른 모든 토큰이 슬롯을 가지므로 예외
  하나는 눈에 띈다 — 문서와 타입 주석에 근거를 적어 두면, 다음 사람이 "빠뜨린 것"으로 보고
  슬롯을 만들려는 시도를 막는다.
- 웹에서는 참조로 남길 이유가 그대로 있다: 테마의 리듬을 바꿨을 때 리터럴 px로 굳은 요소만
  옛 여백에 남으면 그 슬라이드가 옆 슬라이드와 어긋난다.

## 결과

- `gap="md"`(참조)와 `gap="24"`(저자의 리터럴)는 같은 24px이지만 **웹 산출물이 다르다** —
  값 층이 px로 눕히지 않고 토큰 이름을 남기는 이유다 (`soml.Length.Token`).
- PPTX 산출물에서 두 표기는 **구별되지 않는다.** 이것이 이 ADR이 인정하는 손실이고,
  레퍼런스가 그 사실을 명시한다.
- 공간 토큰 CSS 변수는 레이아웃 태그가 있는 덱에만 선언된다 — 참조하는 자리가 컨테이너의
  `gap`/`pad`뿐이라 참조 없는 변수는 골든의 잡음이다.
- 스테이지 여백(64px)은 아직 이 표 밖에 있다 — PRD §8.4의 `slidePadding` 토큰이 들어오는
  Iteration 10이 합칠 자리다.
