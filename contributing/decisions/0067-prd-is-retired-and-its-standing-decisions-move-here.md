# 0067 — PRD.md를 지운다 (남은 결정 12건은 이 ADR이 들고, 인용은 지금의 문서를 가리킨다)

- 상태: 확정
- 날짜: 2026-10-09
- 마일스톤: 정리 (코드 동결)
- 관련: [ADR 0064](0064-the-contract-is-component-and-layout-parity-not-pixel-parity.md)(PRD §13-1을
  대체했다), [ADR 0057](0057-docs-are-hand-written-but-closed-lists-are-read-from-them-by-a-test.md)(문서의
  닫힌 목록), [개요](../../docs/index.md), [레퍼런스](../../docs/reference/index.md), [백로그](../backlog.md)

## 맥락

`PRD.md`(1,176줄)는 구현에 들어가기 전인 2026-08-16에 확정한 제품 정의다. 그 뒤로 일어난 일:

- 구현된 동작은 `docs/reference/`가 적는다. 레퍼런스는 픽스처로 테스트된 것만 담고
  `core/docs_test.go`가 닫힌 목록을 대조하므로 낡지 않는다. PRD에는 그런 장치가 없다.
- 구현 중에 정한 결정은 ADR 66건이 되었고, 그중 여럿이 PRD 본문을 갱신하거나 뒤집었다
  (예: ADR 0064가 §13-1과 §14의 픽셀 지표를 대체했다). 그때마다 PRD도 고쳐야 했고, 고치지 못한
  자리는 두 번째 출처로 남아 서로 어긋났다. PRD가 링크한 `PRELIMINARY.md`는 저장소에 이미 없다.
- 제품의 비전 · 비목표 · 로드맵 · 성공 지표는 [개요](../../docs/index.md)가 이미 같은 내용을 담는다.

반면 PRD의 절 번호(`PRD §7.4`, `PRD §13-5` …)는 ADR을 빼고도 약 120개 파일 — 코드 주석, 레퍼런스,
픽스처 주석, 웹 렌더러가 내보내는 CSS 주석, 그리고 사용자에게 보이는 진단 7종 — 에서 근거로
인용되고 있었다.

## 선택지

1. **PRD를 동결해 남긴다.** 인용은 그대로 유효하다. 그러나 동결한 문서도 읽히고, 읽는 사람은
   어느 절이 아직 맞는지 알 수 없다 — 두 번째 출처가 그대로 남는다.
2. **PRD를 지우고 인용을 특정 커밋의 PRD로 고정한다.** 고칠 것이 가장 적다. 그러나 진단과
   주석이 저장소에 없는 문서를 가리키게 된다.
3. **PRD를 지우고, 인용을 지금 그 내용을 담은 문서로 바꾼다.** 아직 유효한데 다른 어디에도
   적히지 않은 결정(§13)만 이 ADR이 옮겨 든다.

## 결정

**선택지 3.**

1. `PRD.md`를 지운다. 지우기 직전의 판은 커밋 `2121a0b`에 있다.
2. 사용자에게 보이는 진단에서 `(PRD §…)`를 뗀다. 진단은 이유를 문장으로 말하고, 저장소 문서의 절
   번호를 대지 않는다.
3. 코드 주석 · 문서 · 픽스처의 PRD 인용은 아래 대응표의 새 자리로 바꾼다. 인용이 **PRD에만 있던
   계획**(아직 없는 어휘, 원안과 갈라진 자리)을 가리키면 문장을 그 사실로 고쳐 쓴다.
4. 기존 ADR은 고치지 않는다 (ADR은 사후에 고치지 않는다). 기존 ADR 안의 PRD 인용은 커밋
   `2121a0b`의 `PRD.md`를 뜻하고, 아래 대응표로 지금의 자리를 찾는다.
5. 아래 "옮겨 든 결정"은 PRD §13의 번호를 그대로 쓴다 — 인용은 `ADR 0067 결정 5`처럼 쓴다.

### 옮겨 든 결정 (옛 PRD §13)

번호는 옛 §13을 따른다. "구현되지 않았다"고 적은 것은 방향만 정해 둔 것이다 — 구현할 때 이 결정에서
출발하되, 갈라지면 새 ADR이 적는다.

1. **텍스트 줄바꿈** — ADR 0064가 대체했다. 줄이 어디서 접히는지는 계약 밖이고, PPTX 텍스트 몸체는
   `normAutofit`이다. 박스는 잰 크기로 고정하고 스테이지를 넘쳐도 자르지 않는다(오버플로 허용).
2. **확장자는 `.slide` 하나다.** 파일의 역할은 루트 요소와 디렉토리가 정하고 파서가 검사한다.
3. **`<stack>`은 단일 셀 grid 겹침이다.** `at`은 `place-self`, `x`/`y`는 그 자식만 absolute이고
   좌표 기준은 부모의 패딩 박스다 (canvas 직계 자식은 스테이지 패딩 박스 — ADR 0030). z-순서는 문서
   순서(뒤 = 위)이고 z-index 속성은 없다 — 그대로 PPTX 도형 순서가 된다. absolute 전면 방식은
   컨테이너 크기가 사라지므로 배제했다.
4. **`<arrow>` 앵커** *(구현되지 않았다)* — 자동 앵커(중심을 잇는 선이 만나는 변의 중점)가 기본이고,
   `from="db@top"`(4변 + center)이 덮으며, `via`는 공백으로 구분한 논리 좌표점 목록이다. PPTX `cxnSp`
   연결 사이트로 간다.
5. **외관 값 문법.** `gradient(색… [, 각도deg])` — 균등 스톱, 기본 180deg, CSS 각도 시맨틱. 색 변형은
   `shade`/`tint`/`alpha` 3종이고 중첩하지 않는다. 수치는 **단위 없는 논리 스테이지 px** 하나다(`%`만
   예외, 그 밖의 단위는 에러). PPTX 변환은 `1px = 9525 EMU`, 글자 크기 `pt = px × 0.75`.
6. **variant 어휘는 계약에 넣지 않는다.** 이름은 테마의 것이다. 공식 테마가 권장 어휘(`card` ·
   `badge` …)를 공유해 관례를 만들고, 테마에 없는 variant는 에러가 아니라 기본 외관 폴백 + 경고다
   (`--strict`가 올린다).
7. **합성 컴포넌트의 파라미터** *(구현되지 않았다)* — 속성 파라미터와 이름 있는 슬롯까지만. 조건 ·
   반복 · 표현식은 없다 — SOML에는 제어 흐름이 없다. 반복은 SOML을 생성하는 프로그램의 몫이다.
8. **인프로세스 레이아웃 백엔드** *(구현되지 않았다)* — 세 조건을 모두 만족하기 전에는 착수하지
   않는다: ① 텍스트 측정이 골든 코퍼스에서 브라우저와 같은 박스를 낸다 ② flex/grid 좌표가 브라우저와
   100% 같다 ③ 브라우저 없는 CI 수요가 실증된다.
9. **종횡비는 `16:9`(1280×720)와 `4:3`(960×720) 둘이다.** 덱의 `aspect`가 정하고 PPTX 페이지 크기가
   따라간다. 테마는 두 비율을 모두 받아야 한다.
10. **폰트는 임베드하지 않는다.** 테마는 글꼴을 이름 + 폴백 스택으로 적는다. PPTX 임베드는 옵트인으로
    미루고(구현되지 않았다) 라이선스 책임은 사용자에게 있다.
11. **테마는 JS를 담지 않는다.** 테마는 JSON + CSS + 에셋의 데이터 전용 포맷이다 — 원격 테마의 임의
    코드 실행을 막는다.
12. **아이콘 라이브러리를 번들하지 않는다** *(구현되지 않았다)* — `<icon src>`는 로컬 SVG만 받는다.
    벡터는 `<image>`가 아니라 `<icon>`의 자리다.

## 근거

- **출처가 둘이면 낡은 쪽이 읽힌다.** 동결 배너는 "어느 절이 아직 맞는가"를 독자에게 떠넘긴다.
  레퍼런스는 테스트가 붙잡고 ADR은 결정의 날짜를 가지므로, 둘이 가리키는 것이 곧 지금의 사실이다.
- **진단은 저장소 밖에서 읽힌다.** 바이너리를 받은 저자는 `PRD.md`를 열 수 없다. 이유는 문장으로
  충분하다.
- **결정만 옮기면 된다.** PRD에서 다른 문서가 담지 않은 것은 §13의 결정들뿐이었다. 비전과 로드맵은
  개요가, 명세는 레퍼런스가 이미 담는다.

## 결과

- 루트에서 `PRD.md`가 사라진다. 제품 정의는 [개요](../../docs/index.md), 구현된 동작은 레퍼런스, 결정은
  ADR, 남은 일은 [백로그](../backlog.md)다.
- `AGENTS.md`와 [ADR 색인](index.md)이 PRD 대신 이 문서들을 가리킨다. "PRD §13을 뒤집으면 PRD도
  고친다"는 규칙이 "이 ADR의 결정을 뒤집으면 새 ADR을 쓴다"로 바뀐다.
- 진단 7종에서 `(PRD §…)`가 빠진다 (`fix:` 커밋 하나, 골든 `03_layout/golden/diagnostics.txt`).
- 웹 산출물의 CSS 주석이 PRD 대신 레퍼런스를 가리킨다 — HTML 바이트가 한 번 바뀐다.
