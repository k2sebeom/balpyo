# 배치 경고 읽기

슬라이드는 글자 크기 하나로 무너진다. 제목을 두 단어 늘리면 줄이 하나 늘고, 늘어난 줄은
도형 밖으로 흐르거나 스테이지 여백을 먹는다 — 그리고 웹에서는 잘려서, PPTX에서는 슬라이드
밖에 놓여서 **서로 다르게** 어긋난다. 이 가이드는 빌드가 그것을 먼저 말해 주게 만드는 방법이다.

## 켜는 법

```bash
balpyo build --check-layout
```

판정에는 잰 좌표가 필요하므로 이 플래그는 브라우저를 띄운다 (~0.6초). `pptx`를 함께 빌드하면
이미 재고 있으므로 플래그가 필요 없다:

```bash
balpyo build --target html,pptx
```

경고는 빌드를 멈추지 않는다 — 산출물은 그대로 나온다. 넘친 덱을 통과시키고 싶지 않은 CI에서는
`--strict`를 더해 경고를 에러로 승격한다.

## 경고를 읽는 순서

경고는 **넘친 양을 논리 px로** 말한다. 스테이지는 1280×720이고 콘텐츠 박스는 거기서 여백
64px을 뺀 1152×592이므로, "34px 넘친다"는 줄 하나쯤(본문 24px에서 36px)이라는 뜻이다.

### `<p>가 부모 <shape>를 아래로 34px 넘친다`

크기를 정한 박스에 내용이 담기지 않았다. 고칠 길이 셋이다 — 대체로 위에서부터 시도한다.

1. **박스를 키운다**: `<shape h="140">` → `h="200"`. 필요한 높이는 내용 + `pad` 두 벌이다
   (`pad="lg"`는 위아래 각 36px).
2. **글자를 줄인다**: `size` 또는 더 작은 `variant`. 한 슬라이드에서 크기를 두 번 바꾸기
   시작하면 대개 내용이 너무 많다는 신호다.
3. **글을 줄인다.** 슬라이드는 문서가 아니다.

### `<text>가 콘텐츠 박스를 아래로 34px 넘친다`

슬라이드 직계 요소가 스테이지 여백을 침범했다. 대개 한 장에 너무 많이 담은 것이다 — 장을
쪼개거나, `<grid>`/`<row>`로 옆으로 눕히거나, `size`를 줄인다. 여백을 일부러 쓰는 디자인이면
[`layout="canvas"`](../reference/layouts.md)로 좌표를 직접 쓴다: 그 자리는 묻지 않는다.

### `<shape>가 스테이지를 오른쪽으로 120px 벗어난다`

화면 밖이다. 이 경고에는 예외가 없다 — `x`/`y`로 일부러 밀어낸 것이어도 말한다. 웹은 잘라
내고 PPTX는 슬라이드 밖에 도형을 두므로, 두 타깃이 서로 다르게 틀린 산출물이 나온다.
화면 밖으로 넘기는 연출(화면을 벗어나는 큰 글자)은 스테이지 안에서 `<stack>`과 크기로 만든다.

### `<shape>가 형제 <shape>와 164px×64px 겹친다`

같은 부모 안의 두 박스가 서로를 덮었다. 흐름 컨테이너(`<row>`·`<col>`·`<grid>`)에서 이 일이
나면 선언한 크기의 합이 자리보다 큰 것이다 (`w` 셋을 더해 보면 나온다). **겹침이 의도라면**
그것을 어휘로 말한다 — `<stack>`으로 감싸거나 `x`/`y`로 자리를 정한다. 그러면 경고는 사라진다:
배지·꼬리표·워터마크는 겹쳐야 배지다.

### `<pre>의 글줄이 박스를 오른쪽으로 120px 넘친다`

줄바꿈이 불가능한 글자다 — 긴 URL, 공백 없는 식별자, `<pre>`의 긴 줄. 박스는 폭을 넓힐 수
없으므로 글자가 그대로 옆으로 흐른다. 줄을 손으로 나누거나(`<pre>`는 줄바꿈을 보존한다)
`size`를 줄인다.

## 경고가 없다고 완벽한 것은 아니다

이 판정은 **박스가 박스를 벗어났는가**를 본다. 그래서 부모의 여백 안에서 끝난 넘침은 말하지
않는다: `pad="lg"` 도형에서 24px까지는 글자가 여백을 먹어도 조용하다. 거짓 양성을 하나도
내지 않는 대가이고(그래야 `--strict`를 쓸 수 있다 — [ADR 0039](../decisions/0039-layout-warnings-are-box-containment.md)),
그래서 **눈으로 보는 일**을 대신하지는 않는다. 경고 0건은 "사고가 없다"가 아니라 "사고를
숫자로 잡을 수 있는 것은 없다"는 뜻이다.

발표 전 확인은 여전히 두 가지다: 웹 산출물을 열어 넘겨 보고, PPTX를 PowerPoint/Keynote에서
열어 본다.
